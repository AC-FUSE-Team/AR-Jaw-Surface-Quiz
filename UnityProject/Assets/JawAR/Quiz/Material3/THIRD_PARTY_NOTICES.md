# Third-party assets used in the Material 3-inspired Jaw Quiz UI

These assets are used to build a **Unity-native, Material Design 3-inspired** interface. They are
not official Google Material Components/Compose controls — this project uses Unity UI + TextMeshPro
throughout, styled to resemble Material 3 visually.

## Font: Roboto

- Source: https://github.com/google/fonts/tree/main/ofl/roboto (the official Google Fonts
  repository, upstream of fonts.google.com)
- File fetched: `Roboto[wdth,wght].ttf` (variable font), commit at time of download 2026-07-22
- License: SIL Open Font License, Version 1.1 — full text in `Fonts/OFL.txt`
  (copyright 2011 The Roboto Project Authors, https://github.com/googlefonts/roboto-classic)
- Local processing: the variable font was instanced into static weights (Regular/400,
  Medium/500, Bold/700, width=100) using `fonttools` (`varLib.instancer`) so Unity/TextMeshPro can
  generate one SDF font asset per weight. Files: `Fonts/Roboto-Regular.ttf`, `Fonts/Roboto-Medium.ttf`,
  `Fonts/Roboto-Bold.ttf`. `Fonts/Roboto-Variable.ttf` is the original untouched source, kept for
  reference/re-instancing.
- OFL permits this kind of modification (subsetting/instancing) provided the font is not sold by
  itself and the reserved font name isn't used to imply endorsement — neither applies here.

## Icons: Material Symbols (Outlined)

- Source: https://github.com/google/material-design-icons (official Google repository)
- Files fetched: `symbols/web/<icon>/materialsymbolsoutlined/<icon>_24px.svg` for: menu, close,
  volume_off, volume_up, repeat, lightbulb, skip_next, arrow_forward, person, wifi, cloud_off,
  visibility, build, check_circle, error, warning.
- License: Apache License, Version 2.0 — full text in `Icons/LICENSE.txt`
- Local processing: each SVG's path fill was set to white (`#FFFFFF`) and rasterized to a 96×96
  transparent PNG via Inkscape (`Icons/png/*.png`) so a single greyscale-alpha sprite can be tinted
  to any Material color token via `Image.color` at runtime, instead of shipping a separate colored
  asset per state.

## Usage in this project

- `Assets/JawAR/Quiz/Runtime/Material/JawMaterialTheme.cs` — reads the generated TMP font assets.
- `Assets/JawAR/Quiz/Runtime/Material/JawMaterialIcons.cs` — reads the icon sprites.

No icons or fonts in this project were scraped from unverified sources, generated by AI, or used
under an unclear license. No emoji are used as production icons.
